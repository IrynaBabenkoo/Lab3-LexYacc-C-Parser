# Лабораторна робота №3. Синтаксичний аналізатор на базі Lex/YACC

**Тема:** Lex/YACC-based parser

## Мета роботи

У цій лабораторній роботі я реалізувала лексичний і синтаксичний аналізатор для навчальної підмножини мови C. Для розбору використала Python та бібліотеку PLY (Python Lex-Yacc). На основі отриманого абстрактного синтаксичного дерева (AST) додала виконання простих програм, генерацію Python-коду та візуалізацію дерева у браузері.

## Реалізовані можливості

- Розпізнавання ключових слів, чисел, ідентифікаторів, операторів і роздільників.
- Перевірка синтаксису оголошень змінних, присвоєнь, виразів, блоків, `if` / `else` і `while`.
- Побудова AST та збереження його у форматі JSON.
- Обчислення виразів і виконання інструкцій з урахуванням вкладених областей видимості.
- Генерація еквівалентного Python-коду для підтримуваних конструкцій.
- Інтерактивний перегляд AST у браузері через D3.js.
- Автоматичні тести для основних сценаріїв та помилок.

Це **навчальна підмножина C**, а не повний компілятор мови C. Зокрема, не підтримуються функції, вказівники, масиви, цикли `for` і всі правила типізації стандарту C.

## Використані технології

Python 3, PLY 3.11, HTML, CSS, JavaScript, D3.js. Проєкт розроблявся та запускався у VS Code на Windows 11.

## Структура проєкту

| Файл / папка               | Призначення                                     |
| -------------------------- | ----------------------------------------------- |
| `main.py`                  | Запуск аналізу, інтерпретації та генерації коду |
| `lexer.py`                 | Лексичний аналіз на основі регулярних виразів   |
| `parser.py`                | LALR(1)-парсер і побудова AST                   |
| `interpreter.py`           | Виконання AST                                   |
| `codegen.py`               | Генерація Python-коду                           |
| `export_ast.py`            | Експорт AST у `ast.json`                        |
| `index.html`               | Візуалізація дерева через D3.js                 |
| `examples/`                | Приклади вхідних програм                        |
| `tests/`                   | Автоматичні тести                               |
| `requirements.txt`         | Залежності Python                               |
| `ast.json`, `generated.py` | Приклади результатів аналізу та трансляції      |

## Як запустити

Відкрити папку проєкту у VS Code та виконати у терміналі PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py --tokens --ast
```

За замовчуванням аналізується `examples/demo.c`. Програма виводить токени й AST, виконує приклад, зберігає `ast.json` та генерує `generated.py`.

Для аналізу іншого прикладу:

```powershell
.\.venv\Scripts\python.exe main.py examples\dangling_else.c --ast
```

Для перевірки згенерованої програми:

```powershell
.\.venv\Scripts\python.exe generated.py
```

## Перегляд AST у браузері

Після запуску `main.py` відкрити **новий термінал** у корені проєкту:

```powershell
.\.venv\Scripts\python.exe -m http.server 8000
```

Перейти за адресою **http://localhost:8000/index.html**. На сторінці можна змінювати масштаб дерева, переміщувати його та переглядати властивості вузлів. Якщо `ast.json` змінився, натиснути «Оновити AST». Для завантаження D3.js через CDN потрібне підключення до інтернету.

## Перевірка роботи

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тести перевіряють арифметичні вирази, умови, цикли, вкладені області видимості, синтаксичні помилки, ділення на нуль та узгодженість результатів інтерпретації й трансляції на передбачених прикладах.

## Результат

У результаті роботи отримано аналізатор, який проходить усі етапи від токенізації вихідного коду до побудови AST. Для підтримуваної граматики дерево можна виконати, перетворити на Python-код або переглянути графічно у браузері.
